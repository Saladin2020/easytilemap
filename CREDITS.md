# Credits

## Art made for Easy Tilemap (CC0 1.0)

* The `thai_village` tileset (grass variants, blob-47 transitions for dirt, paddy, water and stone, decor
  and editor markers) is drawn procedurally in `src/shared/tileset.ts`; the city rows (sidewalk, asphalt road,
  curb set and street decor) in `src/shared/cityTiles.ts`.
* The 16 objects (stilt houses, temple, sala, market stall, spirit house, trees, bamboo, haystack, water jar,
  lantern post, boat, bridges) are drawn procedurally in `src/shared/objects.ts`; the brick-town objects
  (rowhouses, apartment, garage, corner shop, roof, street tree, shrub, lamp, utility pole, postbox) in
  `src/shared/cityObjects.ts`. The brick-town look was inspired by reference images the user shared; no pixels
  were copied, traced or bundled.
* App icons (`scripts/write-icons.mjs`).

These are dedicated to the public domain (CC0 1.0): use them in any project, no attribution required.

## Sample content

* **Thai town cast** (`samples/characters/town_*`): 48px top-down native sheets composed with
  [Easy Sprite](https://github.com/Saladin2020/easysprite) (kid, vendor, monk, farmer, student, elder) — the
  same cast Easy Dialogue's portraits come from. Same licence as Easy Sprite's parts.
* **Side-view town player** (`samples/side/side_kopiah_boy.*`): Adam, the same kopiah boy as a 48px side-view
  native sheet composed with Easy Sprite (`side_` parts, same colours). Same licence as Easy Sprite's parts.
* Demo maps `thai_village_topdown`, `multicultural_village`, `city_crossing` — MIT, like the code (generated by `src/lib/demoMaps.ts`).
